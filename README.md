# 大肥鱼（dafeiyu-app）

把网页版装进原生外壳的 Android 应用：内层是打包好的 React 单页应用，外层是很薄的原生壳（Kotlin + WebView），再用两个 JS 补丁把系统能力接进来。

## 基本信息

| 项 | 值 |
| --- | --- |
| 应用名 | 大肥鱼 |
| 包名 | `dfy.DeepSeek` |
| 版本 | 0.1.1 |
| 主 Activity | `com.deepseek.chat.MainActivity` |
| 技术 | Kotlin + WebView 外壳，React 产物放在 `assets/` |
| 大小 | 约 5.1 MB |
| 权限 | INTERNET、WAKE_LOCK |
| 原生桥 | `window.__NATIVE__`（enabled / proxyPort / saveFile / downloadVideo / shareText） |

## 功能

### 一、AI 对话

- **多轮对话**：新建对话、历史会话列表、重命名、删除（二次确认）、消息复制、编辑后重新生成、继续生成、多版本消息来回切换
- **角色设定**：可写助手名、性格与说话方式、场景、开场白、示例对话
- **长期记忆 + 历史会话参考**：把过往内容带进新对话
- **联网搜索**：搜索、图像搜索、结果面板（搜索中/已停止/暂不可用都有对应状态）
- **图表与代码**：图表渲染、图表/代码互相切换
- **文件与附件**：上传文件、图片选择、附件随对话保存到本机
- **对话导出**

### 二、生图

- 内置生图入口，可在「数据管理」里配置生图服务
- 支持「选择图片」作为参考、高清出图
- 未配置时会提示先配置生图

### 三、视频解析

- 粘贴抖音分享链接（或口令）直接解析，配合原生 `downloadVideo` 保存视频

### 四、模型与线路

- 模型列表拉取、切换
- 支持自定义中转站、兼容第三方接口（如智谱），可填接口地址与密钥
- 余额不足时提供充值跳转

### 五、外观

- 浅色 / 深色 / 自定义主题

## 补丁脚本（`assets/patch/`）



- **`music.js` — 音乐下载补丁 v2**
  QQ 双音源 + 网易云换源，支持填 VIP cookie；请求经原生 `proxyPort` 转发（`/proxy?u=`）绕开网页跨域限制

## 安装

1. 下载 `dafeiyu-app.apk` 传到手机
2. 允许「安装未知应用」后点击安装
3. 首次启动按提示授予网络权限
4. 在设置里配置模型接口与生图服务后再使用
